CodeAlpha Internship Projects (C++)

1. CGPA Calculator — 
A console-based program that calculates a student's CGPA by converting letter grades into grade points and computing the weighted average based on credit hours.

2. Login and Registration System —
This project is a C++ based Login and Registration System that uses file handling to store user credentials persistently. Registered data is saved to a separate file within the project directory, and a sample of this file has been attached(users.txt) to demonstrate the storage functionality.

3. Banking System —
A C++ console-based Banking System with Customer, Account, and Transaction classes. Supports account creation, deposits, withdrawals, and fund transfers, with automatic file-based storage for transaction history. A sample data file (bank_data.txt) is attached showing stored records.
